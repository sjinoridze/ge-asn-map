How the relationships were inferred

  • Source: RIPEstat asn-neighbours, built from the AS paths seen by RIPE's RIS route collectors. The data is refreshed once a day. A neighbour seen toward the collectors is an upstream; one seen beyond the network is a customer.
  • Noise filter: a transit link counts only when at least 20 collector feeds see it and it carries at least 3% of that network's strongest upstream path. Weaker sightings are usually leaks, remote peering or route-server artefacts.
  • Second source: CAIDA's monthly AS-relationship file, built from both RIPE RIS and RouteViews collectors. Links confirmed by it are marked "CAIDA" in the details panel; links only CAIDA sees are drawn dashed green.
  • Backup links: a weaker live sighting (at least 10 collector feeds) of an upstream the network also declares in RIPE is shown as a backup or lightly used link, not dropped.
  • Confirmed changes: a link counts as added or lost only after it holds for two daily runs, so brief routing flaps don't show up as changes. A link missing for one day stays on the map until confirmed gone.
  • Exchanges and data centers come from PeeringDB, where networks list themselves. Membership at an exchange shows where a network can peer, not with whom.
  • Corrections: links confirmed by operators outside BGP can be added by hand; they are drawn as thick dark lines. Use "Suggest a correction" in the details panel to send one.
  • Mutual transit: both networks pass each other's routes onward, as Magticom and Delta Comm do. These are drawn as dotted links and counted as both upstream and customer of each other.
  • Peering: only peering between networks of the three countries is drawn. Each network's foreign exchange peers are counted in the table.
  • RIPE-only links (…) are still declared in the RIPE database but not seen in any live path. Switch them on with "RIPE-only links" to compare.
  • Blind spots: collectors see paths that reach the global table. A purely domestic link, for example a private link inside one city used only for local traffic, can be missing. … networks announce nothing at the moment and are shown faded.
  • No domestic links: … networks are registered in … but have no live link to any network of the same country. Some are local organisations behind a foreign protection or hosting service (in Georgia, the National Bank and Liberty Bank route via Cloudflare). Most others buy transit only from foreign hosting providers, so the network runs abroad. Pick "No domestic links" in the table filter to list them.
  • Corporate groups: ASNs registered to the same entity are tied with a thick band, plus groups set by hand in the site's configuration (for example Magticom with Delta Comm).
